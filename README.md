# English Learning Hub — интерактивті 3D ағылшын тілі кітабы

Unit 1 «Legend or Truth», Subunit «Survival». 7 тақырып, әрқайсысында Pixar стиліндегі 3D модель.

Кітап үстел үстінде жатқан 3D зат болып көрінеді: мұқаба ашылады, беттер ақтарылады, модель оң жақ беттен көтеріледі, Hoot үкісі кеңес береді. Телефонда да осы 3D кітап ашылады: экранда бір бет көрінеді, төменгі панельдегі текше батырмасы сабақ пен 3D модельді ауыстырады. «Reading mode» қосулы кезде беттер жай беттер болып ашылады, ал модельдің орнында оның фотосы тұрады.

## Фото мен дыбыс

- **Модель фотолары** `public/snapshots/` қалтасында. Модельді өзгерткен соң `npm run dev` іске қосып, `http://localhost:5173/?snapshots` бетін ашыңыз: фотолар қайта сақталады.
- **Сөздердің дыбысы** `public/audio/words/<тақырып>-<нөмір>.mp3` файлдарында, ElevenLabs-тің «Lip» дауысымен жазылған. 6 тақырыптың 58 сөзінің бәрінде дыбыс бар (тізімі `src/content/audio.ts`, тест әр файлдың бар екенін тексереді). Сабақ мәтіндері мен үлгі жауаптарды әзірге құрылғының өз дауысы оқиды.

## Іске қосу

```bash
npm install
```

```bash
npm run dev
```

Тексеру: `npm test` (тесттер), `npm run build` (дайын сайт `dist/` қалтасына шығады).
`dist/index.html` файлын екі рет басып ашуға болмайды: сайтты веб-сервер арқылы ашу керек.

## Тақырыптар

| № | Тақырып | 3D модель | Мазмұн файлы |
|---|---|---|---|
| 1 | Survival: Introduction | Орман лагері, жаңбыр, түн, аңыздағы бұғы | `src/content/theme1.ts` |
| 2 | Being a Tourist: Storytelling | Таулы ауыл, Legend / Truth, First → Finally | `src/content/theme2.ts` |
| 3 | Economics: General Information | Бюджет диаграммасы | `src/content/theme3.ts` |
| 4 | History and Geography | Керуен мен жүк кемесінің картасы | `src/content/theme4.ts` |
| 5 | Degrees of Adjectives | Ғимараттар және Word lab | `src/content/theme5.ts` |
| 6 | Micro & Macroeconomics | Наубайханадан елге дейін | `src/content/theme6.ts` |
| 7 | Progress Check 1 | Нәтиже мұнаралары | `src/content/quiz.ts` |

Мәтінді өзгерту үшін тек `src/content/` файлдарын түзетсе жеткілікті.
3D модельдер `src/scenes/` қалтасында (жұмсақ пішіндер — `src/scenes/toon.ts`), үстел мен кітап — `src/core/desk.ts`, есептеу логикасы `src/logic/` қалтасында.

## Мазмұн туралы

- Тақырып атаулары берілген жоспардан, 30 сұрақ пен жауап кілті `Progress_Check_1_Worksheet.pdf` файлынан алынды.
- Оқу мәтіндері, сөздік, қазақша аудармалар, жаттығулар мен мұғалім жазбалары жаңадан жазылды.
  **Сабақта қолданар алдында мұғалім тексеруі керек.**
- Тест жауаптары сайт кодында бар, сондықтан ол өзін-өзі тексеруге ғана арналған.
- «Listen» батырмасы браузердің дауыс синтезін қолданады; дауыс құрылғыға байланысты.
- Оқушының прогресі тек сол браузерде сақталады.

## GitHub Pages-ке шығару

Репозиторий баптауында **Settings → Pages → Source: GitHub Actions** таңдаңыз.
Содан кейін `main` тармағына жіберілген әр өзгеріс `.github/workflows/deploy.yml` арқылы жарияланады.
`материалы для книга` қалтасы `.gitignore`-да: онда мұғалімнің жауап кілті бар.

`project-plan.md` бастапқыда физика кітабына жазылған; бұл жобада оның кітап механикасы алынды.
Әзірге жасалмағандары: бөлек Astro лендингі, бір файлды офлайн нұсқа, Blender модельдері.
